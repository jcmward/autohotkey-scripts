# AutoHotkey Scripts

## Overview

These are some AutoHotkey v2 scripts to make my life easier.

As a Vim user, I need an Escape key close to the home row.
I also much prefer the Control key to be where CapsLock is, to avoid contorting my hand and wrist into awkward positions, for example when pressing Ctrl+T.
Fortunately, we can get CapsLock to serve both functions, depending on whether it is held down in combination with another key or tapped and released on its own.

Estoy aprendiendo español (I'm learning Spanish), so I need to be able to type certain letters with accents.
I don't like switching keyboard languages just for a handful of special characters; I find it somehow clunky and confusing, so instead I just remap some keys.

## Features

- Easily insert accented letters (for Spanish) and some other Unicode symbols
- CapsLock sends Control (when combined with another key) or Escape (when tapped)
- Right Alt sends Control (when combined with another key) or Backspace (when tapped)
- Press both Shift keys together to toggle CapsLock state
- Miscellaneous useful hotkeys

## Usage

Install AutoHotkey v2 and use it to run `keymaps.ahk`.
